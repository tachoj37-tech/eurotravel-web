# El corte, en números

Lo que dejaron las conversaciones de **todavía ningún corte**.

> Se llena sola con `npm run corte`, cada quince días. Si corrijo
> algo aquí a mano, la siguiente corrida me lo pisa.

**Aquí no hay datos de nadie, a propósito: son cuentas.** Las
conversaciones enteras quedan fuera del repositorio, en la carpeta
`conversaciones/`, y de ahí se lee para mejorar el criterio.

---

**En este corte no hubo ninguna conversación guardada.** Si el bot sí
estuvo contestando, lo que falta es el almacén: ver
`docs/EL-CORTE.md`.
