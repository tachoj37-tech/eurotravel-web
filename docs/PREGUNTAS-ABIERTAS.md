# Lo que no tengo claro

Pedido por el dueño el 1-sep-2026: *«dame todas las preguntas de lo que no
sabes y te las respondo para que esté claro»*.

**Van numeradas para poder contestarlas de corrido**: «1: sí», «2: son 2,500»,
«3: está bien», etc. No hace falta contestarlas todas de una sentada — las que
se contesten se van de aquí y entran al criterio con su fecha.

Están ordenadas por **cuánto dinero mueven**. Cada una trae lo que la página
cobra **hoy**, medido, para poder contestar mirando un número y no una
abstracción.
